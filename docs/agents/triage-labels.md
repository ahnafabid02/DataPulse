# Triage labels

Canonical roles map to GitHub labels with the same names:

- `needs-triage`: maintainer needs to evaluate the issue.
- `needs-info`: waiting on the reporter for more information.
- `ready-for-agent`: fully specified and ready for agent implementation.
- `ready-for-human`: requires human implementation or judgment.
- `wontfix`: will not be actioned.

When a skill names a triage role, use the corresponding label above.
Edit this mapping if the project's label vocabulary changes.
